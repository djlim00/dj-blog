# 1. 카프카 커넥트

![[Pasted image 20260726111955.png]]

- 데이터 파티프라인 생성 시 반복 작업을 줄이고 효율적인 전송을 이루기 위한 애플리케이션.
	- 특정한 작업 형태를 **"템플릿"** 으로 만들어 놓은  커넥터를 실행


### 커넥트 내부 구조

![[Pasted image 20260726112043.png]]

- 사용자가 커넥트에 커넥터 생성 명령 -> 내부에 커넥터와 태스크를 생성
	- <mark class="hltr-yellow">커넥터는 태스크를 관리</mark>
	- <mark class="hltr-yellow">태스크는 커넥터에 종속되는 개념으로 실질적인 데이터를 처리</mark>
	- 태스크 상태를 보면 정상 처리 여부를 확인 가능


# 2. 커넥터

### 1. 소스 커넥터(프로듀서), 싱크 커넥터(컨슈머)

- 소스 커넥터는 데이터를 카프카 토픽으로 전송
- 싱크 커넥터는 토픽의 데이터를 파일로 저장(컨슘)

- <mark class="hltr-yellow">MySQL, S3, MongoDB는 대표적인 싱크 애플리케이션, 소스 애플리케이션</mark>
	- MySQL에서 카프카로 데이터를 보낼 때, 카프카에서 데이터를 MySQL에 저장할 때 JDBC 커넥터를 사용해 파이프라인 생성


### 2. 커넥터 플러그인

![[Pasted image 20260726112410.png]]

- 추가적인 커넥터 -> 플러그인 형태의 jar 파일 추가
	- 직접 구현하거나, 가져다가 쓸 수 있음.


### 3. 컨버터, 트랜스폼

- 컨버터 : 데이터 처리하기 전에 스키마를 변경하도록 도와줌
- 트램스폼 : 메시지 단위로 데이터를 간단하게 변환
