# 1. Spring Batch 왜 필요할까?

### 배치 처리란?
- <mark class="hltr-yellow">대량의 데이터를 정해진 시간에 자동으로 일괄 처리하고, 결과를 출력하는 방식</mark>

1. Scheduler
	- 간편함 : `@Scheduled`로 빠르게 구현 가능
	- 단순처리에 능함(소량 데이터)
	- 그렇지만 만약 단순 반복으로 100만명에게 쿠폰을 지급하면..?
		- 메모리 부족 :  Out Of Memory
		- 복구 불가능 : 중간에 실패하면 DB를 조회해서 대조해야함
		- 관리 포인트 부재 : 현재 실행을 확인할 수가 없음

2. Batch
	- 대용량 특화 : 데이털를 일정한 크기로 잘라서 처리
	- 견고함 : 실패 시 메타데이터를 참조해서 실패한 지점에서 재시작 가능
	- 모니터링 & 통계 : 프레임워크가 실행이력을 전용 DB 테이블에 자동으로 기록

### 실무 활용은 어떻게?
- 리포트 생성 : 생성된 매출 통계나 같은 데이터를 집계해서 보고서 작성
- 정산 시스템 : 결제 내역을 바탕으로 정산금 지급
- 데이터 정리 : 오래된 로그 삭제 및 데이터 아카이빙
- 백업 및 마이그레이션 : 대규모 데이터 이동 및 백업 작업

# 2. Spring Batch는 참 좋다..!

### 1. 뛰어난 유지보수성
- 배치 코드는 한 번 구축하면 비즈니스 로직이 크게 변하지 않고, 안정적으로 가동되어야함
- Spring의 뛰어난 유지보수성을 Spring Batch도 가지고 있음
- ![[Pasted image 20260806110944.png|496]]

### 2. 다양한 데이터 소스 지원
- RDB는 물론이고, XML, JSON, NoSQL, CSV 같은 다양한 포맷을 지원
- ItemReader와 ItemWriter 인터페이스로 구현체를 만들 수 있음


### 3. 강력한 장애 복구
- 중간에 오류 발생 -> 재시작 가능

### 4. @Configuration 어노테이션
- 너무 편하게 설정 가능

### 5. JUnit을 통해서 편하게 테스트 가능
- 이외에도 Spring에서 사용하던 테스트 도구를 자유롭게 사용가능

# 3. Spring Batch의 핵심 컴포넌트 - Job, Step, Repository, Operator

![[Pasted image 20260806111236.png]]

#### 1. Job
- 배치 처리의 가장 큰 단위(전체 흐름)
- ex) 매월 1일에 처리되는 "이자지급Job"

#### 2. Step
- Job을 구성하는 세부 단계 - 실제 작업이 일어나는 실행 단위
- <mark class="hltr-yellow">하나의 Job은 여러개의 Step</mark>
- ex) 오래된 로그 정리 Step
	1. Read : 특정 날짜 이전의 로그 데이터 조회
	2. Process : 중요한 정보가 없는지, 필터링 및 확인
	3. Write : 선별된 오래된 데이터를 삭제 처리

#### 3. JobRepository
- 배치 실행 관련 메타데이터를 DB에 저장 및 관리
- <mark class="hltr-yellow">Job과 Step의 시작/종료 시간, 성공/실패 여부, 읽은 데이터 수</mark>
- 모니터링 단계에서 활용

#### 4. JobOperator
- JobLauncher를 포함하여 중지/재시작 등 관리 기능까지 제공하는 인터페이스
- <mark class="hltr-yellow">사람이 배치를 제어할 수 있는 "운영 조작 패널" 역할</mark>
- 내부적으로는 JobLauncher를 사용해서 Job 구동시킴

# 3. 실습 시작하기

```java title:카페시뮬레이션

package com.system.batch.sy_batch_system.chap02;  
  
import lombok.RequiredArgsConstructor;  
import org.springframework.batch.core.job.Job;  
import org.springframework.batch.core.job.builder.JobBuilder;  
import org.springframework.batch.core.repository.JobRepository;  
import org.springframework.batch.core.step.Step;  
import org.springframework.batch.core.step.builder.StepBuilder;  
import org.springframework.batch.infrastructure.repeat.RepeatStatus;  
import org.springframework.batch.infrastructure.support.transaction.ResourcelessTransactionManager;  
import org.springframework.context.annotation.Bean;  
import org.springframework.context.annotation.Configuration;  
import org.springframework.transaction.PlatformTransactionManager;  
  
@Configuration  
@RequiredArgsConstructor  
public class CafeJobConfig {  
  
    private final JobRepository jobRepository;  
    private final PlatformTransactionManager transactionManager;  
  
    private int coffeeCount = 0;  
    private final int ORDER_TARGET = 5;  
  
    // 1. 카페 문 열기    => openCafeStep  
    // 2. 커피 만들기(5잔) => makeCoffeeStep    // 3. 마감 청소 및 퇴근 => closeCafeStep  
    @Bean  
    public Job cafeJob(){  
        return new JobBuilder("cafeJob", jobRepository)  
                .start(openCafeStep())  
                .next(makeCoffeeStep())  
                .next(closeCafeStep())  
                .build();  
    }  
  
  
    @Bean  
    public Step openCafeStep(){  
        return new StepBuilder("openCafeStep", jobRepository)  
                .tasklet((contribution, chunkContext) -> {  
                    System.out.println("[오픈] 카페 문을 열고 머신을 예열 합니다.");  
                    return RepeatStatus.FINISHED;  
                }, new ResourcelessTransactionManager())  
                .build();  
    }  
  
    @Bean  
    public Step makeCoffeeStep(){  
        return new StepBuilder("makeCoffeeStep", jobRepository)  
                .tasklet((contribution, chunkContext) -> {  
                    coffeeCount++;  
                    System.out.println("[제조] 아메리카노 " + coffeeCount + "잔 째 완성!");  
  
                    if(coffeeCount < ORDER_TARGET){  
                        return RepeatStatus.CONTINUABLE;  
                    }else{  
                        System.out.println("[완료] 주문하신 커피 " + ORDER_TARGET + "잔 나왔습니다.");  
                        return RepeatStatus.FINISHED;  
                    }  
                }, transactionManager)  
                .build();  
    }  
  
    @Bean  
    public Step closeCafeStep(){  
        return new StepBuilder("closeCafeStep", jobRepository)  
                .tasklet((contribution, chunkContext) -> {  
                    System.out.println("[마감] 머신을 끄고 퇴근합니다. 오늘도 수고하셨습니다.");  
                    return RepeatStatus.FINISHED;  
                }, transactionManager)  
                .build();  
    }  
  
}
```
